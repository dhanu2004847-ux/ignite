# Campus Connect Lost & Found System

A smart web-based platform for managing lost and found items in campus environments.

-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

## 📖 Project Description

Campus Connect is a web-based Lost & Found Management System developed to help students and staff easily report, track, and recover lost belongings within a campus environment.

The system provides a centralized platform where users can:

* Report lost items
* Register found items
* Submit claim requests
* Track recovery status
* View smart matching suggestions

The platform also includes intelligent algorithms to improve efficiency and transparency in the lost-and-found process.

--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

## 🚀 Features

### 🔹 Lost Item Reporting

Users can submit details about lost items including:

* Item name
* Category
* Location
* Date
* Contact information

### 🔹 Found Item Registration

Users can register items they found on campus.

### 🔹 Claim Request System

Users can claim found items by providing proof and ownership details.

### 🔹 Smart Matching Algorithm

The system compares lost and found items using a score-based matching algorithm.

### 🔹 Priority Ranking Algorithm

Items are ranked based on urgency and importance.

### 🔹 Claim Validation Algorithm

Claim requests are evaluated using confidence scoring.

### 🔹 Admin Dashboard

Admins can monitor:

* Lost items
* Found items
* Claim requests
* System activity

## ⚙️ Installation Steps

1. Clone the repository

```bash
git clone https://github.com/dhanu2004847-ux/ignite.git
```

2. Open the project in IntelliJ IDEA

3. Make sure JDK 17 is installed

4. Run the main class:

```bash
CampusConnectApplication.java
```

5. Open browser and visit:

```bash
http://localhost:8080
```
